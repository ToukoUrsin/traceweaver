01 / COMPILE

Catch impossible rules.

A real lexer and parser build typed event schemas. Correlation fields must exist on both events and have the same type. Diagnostics point to the source line and column.

02 / REPLAY

Close a window, not a guess.

Expectations stay pending until a match or deadline. Forbidden events fail immediately. Deadlines include events at the exact boundary; written order breaks timestamp ties.

03 / EXPLAIN

Keep the evidence small.

A forbidden-event witness needs two events. A missing-event witness needs a trigger plus a closed, complete trace window. It is evidence about this trace, not a claim about unseen reality.
