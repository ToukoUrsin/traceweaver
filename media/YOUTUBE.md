## Title

Traceweaver: a tiny temporal language for event-stream promises (Syntax Summit demo)

## Description

Traceweaver is an original domain-specific language for promises about time, like "every deployment becomes healthy within thirty seconds". Declare typed events, write expect/forbid rules with a time window and correlation fields, then replay a trace and see why each obligation is pending, fulfilled or violated.

This demo shows the actual working app: writing a program, compiling it, replaying the trace, a located compile diagnostic, export and reimport with recomputed results, and the same interpreter from the command line with its test suite.
